# Security and privacy

TaxPath is a non-official, local prototype. It must never connect to government systems or collect real citizen data.

- No PAN, Aadhaar, bank account, portal password, or actual Form 16 is requested.
- The visible upload is a controlled synthetic parser flow, not a file-processing endpoint.
- Demo scenarios contain only fictitious information.
- Theme preference is the only persisted browser state.
- Tax estimates are deterministic and explicitly marked as prototype estimates.
- A production version would require threat modelling, server-side validation, encryption, consent handling, retention policy, audit logs, and professional legal/tax review.
